# Плагин устройств X-Keeper для Codex

Плагин подключает к Codex удалённый MCP-сервер, доступный только для чтения, и добавляет русский навык выбора инструментов X-Keeper. Переменные окружения и отдельная авторизация MCP не нужны.

В начале задачи пользователь передаёт свой ключ API `devices-api` в диалоге. Модель подставляет ключ в каждый вызов инструмента. Можно написать, например, «используй этот ключ как Рабочий: ...», а затем ссылаться на имя `Рабочий` в рамках той же задачи.

Ключ не сохраняется MCP-сервером и не переносится автоматически в другую задачу. Пользователь должен передать его заново после начала новой задачи или потери контекста.

Для запросов про устройства, SIM, статусы, настройки, историю, геозоны, группы, списки, объекты и отчёты навык направляет модель в MCP X-Keeper. Pinokio, браузер, терминал и прямые HTTP-запросы для этих задач использоваться не должны.
