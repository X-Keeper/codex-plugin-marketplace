# Плагин устройств X-Keeper

Плагин подключает read-only MCP `https://mcp.rnd.x-keeper.net/mcp` и навык выбора инструментов X-Keeper.

При установке пользователь один раз проходит OAuth. Код доступа MCP, сервисный ключ, raw-secret и пароль устройства в запросах инструментов не нужны.

Пользовательский `apiKey` запрашивается только для кабинетных инструментов: групп, списков, объектов, общего списка геозон и отчёта о перевёрнутых устройствах.

История и настройки поддерживают поиск по `device_hash`, SIM1/2, GSM IMEI и Wi-Fi IMEI. Плагин предоставляет только чтение.
