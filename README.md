# Marketplace плагинов X-Keeper для Codex

Публичный репозиторий с marketplace и плагином Codex для чтения данных устройств X-Keeper через удалённый MCP-сервер.

Реализация MCP-сервера и `devices-api` в этот репозиторий не входят. Плагин подключается к готовому адресу `https://mcp.rnd.x-keeper.net/mcp`.

## Установка через интерфейс

1. Открыть каталог плагинов в Codex.
2. Выбрать добавление marketplace.
3. В поле источника указать `X-Keeper/xk-codex-markeplace` или `https://github.com/X-Keeper/xk-codex-markeplace.git`.
4. Открыть источник `X-Keeper`.
5. Установить плагин «Устройства X-Keeper».
6. Если источник не появился сразу, перезапустить приложение.

Репозиторий должен быть публичным, чтобы пользователям не требовалась авторизация в GitHub. Подтверждение компании OpenAI для установки из этого marketplace не требуется.

Ссылка на репозиторий, отправленная в обычный чат, не устанавливает плагин автоматически. Её нужно указать именно в форме добавления marketplace.

## Использование

В начале новой задачи передайте свой ключ API `devices-api` и сформулируйте запрос. Например:

```text
Используй ключ ВАШ_API_КЛЮЧ и получи статус устройства с SIM НОМЕР_SIM.
```

Модель передаёт ключ в каждый вызов MCP в пределах текущей задачи. MCP не сохраняет ключ, поэтому в новой задаче его нужно указать снова.

Плагин поддерживает только чтение. Действительность ключа и доступ к устройствам проверяет `devices-api`.

## Обновление

После изменения манифеста, MCP-подключения или навыка нужно выпустить новую версию плагина и опубликовать изменения в этом репозитории. Пользователь обновляет источник marketplace и переустанавливает плагин, после чего начинает новую задачу Codex.
