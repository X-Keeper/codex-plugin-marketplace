# Правила разработки marketplace X-Keeper

## Состав проекта

- Проект содержит только публичный marketplace, плагин Codex, подключение к удалённому MCP и навыки.
- Реализация MCP-сервера, OpenAPI, Docker и конфигурация развёртывания находятся в отдельном приватном репозитории.
- Весь пользовательский текст, описания, подсказки и инструкции должны быть на русском языке.

## Безопасность

- Нельзя добавлять API-ключи, пароли, токены или другие реквизиты доступа в файлы проекта.
- MCP должен подключаться только к `https://mcp.rnd.x-keeper.net/mcp`.
- Навык должен разрешать только чтение и не должен предлагать изменяющие или удаляющие операции.
- Пользователь один раз проходит OAuth при подключении MCP.
- Сервисные инструменты не запрашивают API-ключ, пароль устройства или raw-secret.
- Пользовательский `apiKey` разрешён только для кабинетных read-only инструментов, в схеме которых он обязателен.
- Плагин и навык не являются границей безопасности: доступ к данным проверяет `devices-api` через MCP-сервер.

## Структура плагина

- Marketplace находится в `.agents/plugins/marketplace.json`.
- Плагин находится в `plugins/xkeeper-devices`.
- Манифест находится в `plugins/xkeeper-devices/.codex-plugin/plugin.json`.
- MCP-подключение находится в `plugins/xkeeper-devices/.mcp.json`.
- Навык находится в `plugins/xkeeper-devices/skills/xkeeper-read-devices`.
- При выпуске новой версии плагина нужно обновлять поле `version`, чтобы Codex не использовал старую копию из кэша.

## Обязательные проверки

- Проверить плагин валидатором `plugin-creator`.
- Проверить навык валидатором `skill-creator`.
- Убедиться, что marketplace указывает на `./plugins/xkeeper-devices`.
- Убедиться, что в проекте нет секретов и ссылок на локальные файлы.
